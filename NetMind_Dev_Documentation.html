Developer Reference

Technical documentation detailing the inner workings of the NetMind React Canvas, AI Configuration flows via Google Genkit, and real-time database synchronization via Firebase.

Core Application Architecture

NetMind is built on a modern React / Next.js (App Router) stack. Unlike open-source projects, NetMind is engineered for scalable deployment on cloud providers like Azure or Cloudflare.

  • Frontend: Next.js 14, React 18, TailwindCSS. The canvas is rendered using raw SVG paths and DOM nodes for maximum performance during drag/pan operations.
  • Backend/Server Actions: Next.js Server Actions execute Genkit flows securely away from the client browser.
  • Database & Auth: Firebase Firestore provides real-time document synchronization. Firebase Authentication handles user identity securely.

The Canvas Engine

Mathematical Logic & Edge Routing

The canvas (editor-client.tsx) operates by storing a serialized state of nodes (devices/text) and edges (connections). Edges are dynamically routed using geometric algorithms.

Closest Anchor Finding

Devices generate 16 equidistant anchor points around their bounding box. When a connection is drawn, the engine calculates the Euclidean distance between all possible anchors on both devices to ensure lines never cross through the device body.

Orthogonal Pathing & Control Points

For 'orthogonal' and 'curved' connection types, control points can be added. The engine generates SVG paths (M x,y L x,y or Q x,y x,y) based on the user's manipulation of these control points.

AI Configuration Engine (Genkit)

NetMind utilizes the Google Genkit framework (src/lib/ai-flows.ts) bridging to gemini-1.5-flash. This engine analyzes the serialized JSON topology of the canvas and compiles it into syntax-accurate network configurations.

src/lib/ai-flows.ts TypeScript 

import { genkit } from 'genkit';
import { googleAI } from '@genkit-ai/googleai';
import { z } from 'zod';

const ai = genkit({ plugins: [googleAI()] });

export async function generateSingleDeviceConfiguration(input) {
  const { output } = await ai.generate({
    model: 'googleai/gemini-1.5-flash',
    prompt: `You are an expert network engineer...
    Identify the role of the target device from its 'type' and 'name'.
    Use IP addresses from the nearby text labels to configure interfaces.`,
    output: { schema: GenerateSingleDeviceConfigurationOutputSchema },
  });
  return output;
}

Contextual Association Rule

The AI relies on spatial coordinates. It associates a loose text node (like "10.10.1.0/30") with the physical line or device closest to it on the canvas coordinate plane.

Multi-Vendor Future

Currently, prompts are strictly defined for Cisco IOS. Future iterations will introduce vendor-flags (Fortigate, Aruba) dynamically injected into the Genkit prompt.
